DME Office · connection check

This page checks each part of the setup and says what to fix. It changes nothing.

    Install as an app

    Checks the files a phone needs to install the DME Office with its logo.

      Android (Chrome): open the app link in Chrome itself (not inside WhatsApp or Gmail; tap ⋮ › Open in Chrome). Tap ⋮ › Install app (or Add to home screen › Install). If it only offers Create shortcut, one of the checks above is ✗.

      iPhone (Safari): open the link in Safari, tap the Share button › Add to Home Screen › Add.

      If you added it before these files were in place, delete the old home-screen icon first, then add it again.
